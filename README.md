# Markdown Editor

Lightweight Markdown write + preview tool.

## Features
- Split editor / preview
- Headings, bold, italic, code, lists, links, blockquotes
- Copy Markdown source

## Limitations
- Not CommonMark-complete; no plugins/GFM tables
- Preview is sanitized-ish via text escaping before simple transforms

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
